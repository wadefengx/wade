Get Started View on GitHub
Terminal — zsh 
# Switch npm/yarn/pnpm to taobao mirror
$ wade registry use taobao
Switched to taobao (https://registry.npmmirror.com/)

# Install and use Node 20
$ wade node install 20
Downloading node-v20.20.2-darwin-arm64.tar.gz...
Node v20.20.2 installed ✓

$ wade node use 20
Now using v20.20.2

# Check status
$ wade status
Registry:  taobao
Node ver:  v20.20.2 (default)

Why Wade?

🎯

One binary, zero drama

Single Go binary. No Node.js dependency. Install once, use forever. No more "command not found" when you switch Node versions.

🔄

Registry for all PMs

One command switches npm, yarn, AND pnpm registries simultaneously. 5 built-in mirrors + unlimited custom registries.

⚡

Instant switching

Version switching via symlinks — no shell reload, no PATH manipulation. Faster than nvm.

🇨🇳

China-friendly

Node binaries downloaded from npmmirror.com by default. Built-in taobao, tencent, huawei registries.

🖥️

Cross-platform

macOS, Windows, Linux. Same binary, same commands, same experience.

📋

Spec-driven

Every feature is defined in SPEC.md before implementation. AGENTS.md guides AI-assisted development.

Installation

From Source

git clone https://github.com/wadefengx/wade.git
cd wade
go build -o ~/.local/bin/wade .
wade setup

Homebrew (macOS)

brew install wadefengx/tap/wade ← coming soon

Scoop (Windows)

scoop bucket add wade https://github.com/wadefengx/scoop-wade
scoop install wade ← coming soon

After installation, add ~/.wade/shims to your PATH:

echo 'export PATH="$HOME/.wade/shims:$PATH"' >> ~/.zshrc
